# Тест политического компаса

Точный тест политического компаса из 44 утверждений по двум осям:

- **Экономическая** ось: Левые ↔ Правые
- **Социальная** ось: Либертарианство ↔ Авторитаризм

В конце теста определяется точная или ближайшая идеология (метод ближайшего соседа среди 27 идеологий) и выводится изображение положения на координатах (с возможностью скачать PNG).

## Запуск

Сайт — статический (`index.html`), без зависимостей. Опубликован через GitHub Pages:

https://omnizs38.github.io/political-compass-test/

Локально достаточно открыть `index.html` в браузере.
